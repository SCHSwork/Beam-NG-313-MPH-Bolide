# Velocità — Civetta Bolide mod for BeamNG.drive

Two configs for the Civetta Bolide (they appear under the Bolide in the vehicle selector):

- **Velocità** — RWD, ~1000 hp quick-spool twin-turbo 3.9 V8, 7-speed dual-clutch, nitrous
- **Velocità AWD** — all-wheel drive (62% rear limited-slip center diff), ~1100 hp, bigger nitrous shot, drift mode

## Features
- Traction control, stability control, ABS, launch control (TCS / ESC drive-mode button)
- Torque-vectoring rear limited-slip diff
- Active rear wing: flat on straights, raised in corners, air brake under hard braking
- Speed-sensitive steering with anti-snap smoothing
- Carbon-ceramic brakes, endurance cooling package, straight-through exhaust
- AWD drift mode (88% rear)

## Install
Zip the `vehicles` and `lua` folders (keeping the folder structure) and drop the zip into
`BeamNG.drive/current/mods/`. Fully restart BeamNG after updating — hot-reloading a changed zip can break config loading.
